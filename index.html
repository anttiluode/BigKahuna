WHAT THE NEEDLE DOES

Choose a revealing question.

Each record predicts a response to 16 possible probe directions. The needle asks where the records currently disagree most, then updates its belief from the answer.

It asks only when uncertainty about the current output exceeds the question’s price. This is a designed rule, not a learned curiosity system.

WHAT IT HAS TO BEAT

Simple methods get a fair turn.

Feedback only tracks which record explains recent outcomes. Fixed probe uses a direction chosen once from calibration. Random probe samples the same direction bank.

All share the record bank, noise assumptions and switching model. Probe policies share the same gate and one-query-per-round ceiling. Actual queries and computation can differ.

WHERE IT CAN FAIL

Looking busy isn’t learning.

Try expensive questions, rapid switches, or identical records. Asking can waste resources. Pure rotations offer no preferred direction in the exact model.

This tests retrieval of familiar rules. Learning new rules, protecting memories during writes, and choosing its own goals remain open.
