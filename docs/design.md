# BigKahuna: asking before acting

Build a dependency-free static browser laboratory in the user-supplied GitHub repository. The user authorized implementation and publication on 2026-10-27 after the conversation's concrete experiment proposal.

Four 2×2 operators are learned from a separate, clearly identified curriculum and then frozen. During evaluation an unobserved Markov process switches among them. All selectors see the same ordinary input and receive the same noisy output only after predicting. Three selectors may purchase one extra unit-norm diagnostic input before predicting. Hidden identity is available only to the environment, scoring and the explanatory display.

Compare a Bayesian recent-feedback tracker, calibrated fixed probe, random probe and posterior-disagreement probe. Query policies share a gate: predicted mean squared output uncertainty at the current ordinary input must exceed the query price. The gate and Bayesian update are designed algorithms, not learned policies. The fixed probe maximizes uniform-prior disagreement over the same candidate directions. Query price is an explicit utility tradeoff, not measured computer time. The environment stays fixed during a probe and its subsequent prediction.

Presets: directional operators, rotations (no direction advantage for exact matrices), identical operators (unidentifiable), rapid switches and expensive queries. Same training, data, observation noise, assumed hazard, maximum query count, amplitude budget and scoring for all arms. Independent random streams prevent a policy's actions from changing future inputs. Count actual queries and candidate evaluations; do not claim equal compute.

The browser shows records, hidden truth clearly labeled as evaluator-only, pre-feedback beliefs, probe and prediction, cumulative charged loss, results table and readable verdict. Run/pause/step/finish/reset, scenario/noise/cost/seed controls and JSON export. Responsive, keyboard-usable, reduced-motion aware. No external fonts, services or dependencies. CLI benchmark writes seed-level receipts; no unsupported advantage claims.

Alternatives considered: parabolic Sihti filtering and ETH interpolation are deferred because they address different questions. This is conventional active identification applied to an explicit Kahuna failure, not a new learning law or implementation of either theorem.
